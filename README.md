# 오늘뭐먹지 — 아이 식단 도우미

아이 밥 뭐 해줄지 매일 고민하는 부모를 위한 단일 파일 웹앱입니다. 빌드·설치·로그인·서버 없이 `index.html` 하나로 동작합니다.

> [mungbws1031/cook](https://github.com/mungbws1031/cook)의 "전자혀" 맛 튜닝 계산기를 기반으로, 냉장고 재료 관리·사먹는 메뉴 추천까지 아이 식단 전반을 다루는 앱으로 새로 분리했습니다.

## 실행

```bash
# 가장 간단 — 파일을 더블클릭
index.html

# 또는 로컬 서버 (폰에서 같은 와이파이로 접속하려면)
python -m http.server 8000
```

## 기능 (하단 탭)

| 탭 | 내용 |
|---|---|
| 🎚️ **탐색** | 5축 슬라이더로 맛 배합을 실시간 예측하는 시뮬레이터 |
| 🧮 **계산** | 음식 무게·스타일 → 양념 배합표(g + 숟가락 환산) |
| 🍙 **요리** | 쉬운 요리·파인다이닝 레시피, 찜 저장 |
| 🥫 **소스** | 인기 소스 배합 계산 |
| 📅 **식단** | 일주일 식단표 + 자동 장보기 리스트 |
| 🧊 **냉장** | 재료 구입일·유통기한 관리, 만료 알림, 보유 재료로 만들 수 있는 요리 추천 |
| 🛍️ **사먹기** | 쿠팡·이마트·배달 브랜드 아이 메뉴 큐레이션, 맵기 필터, 랜덤 추천 |
| 🩹 **보정** | 망한 음식 증상별 처방 |
| ★ **저장** | 계산 결과·레시피·소스 찜 모음 |

모바일 우선 설계, PWA로 홈 화면에 설치해 앱처럼 사용할 수 있습니다.
