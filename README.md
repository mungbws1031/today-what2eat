# 오늘뭐먹지 — 아이 사먹기 메뉴 추천

쿠팡·이마트·배달 브랜드에서 아이 사먹일 메뉴를 고를 때 쓰는 단일 파일 웹앱입니다. 빌드·설치·로그인·서버 없이 `index.html` 하나로 동작합니다.

> [mungbws1031/cook](https://github.com/mungbws1031/cook)("전자혀")의 "사먹기" 탭만 떼어내 독립 앱으로 분리했습니다. 맛 계산·냉장고 관리 등 나머지 기능은 전자혀 쪽에 있습니다.

## 실행

```bash
# 가장 간단 — 파일을 더블클릭
index.html

# 또는 로컬 서버 (폰에서 같은 와이파이로 접속하려면)
python -m http.server 8000
```

## 기능

- **어디서**: 전체 / 🛒쿠팡 / 🏬이마트 / 🛵배달 필터
- **종류**: 밥·한끼 / 치킨 / 피자·버거 / 분식 / 간식·디저트
- **우리 아이 매운 정도** 슬라이더 — 상한을 넘는 매운 메뉴는 자동으로 숨김
- **🎲 오늘 뭐 사먹지?** — 조건에 맞는 메뉴 중 랜덤 추천
- 메뉴 카드마다 맵기·연령·가격대·한줄평 + 쿠팡/이마트몰/배달 검색 바로가기
- ❤️ 찜하면 목록 최상단 고정 (localStorage)

모바일 우선 설계, PWA로 홈 화면에 설치해 앱처럼 사용할 수 있습니다.
